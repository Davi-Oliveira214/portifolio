# 💼 Meu Portfólio

Este projeto foi desenvolvido como parte do meu portfólio profissional. O site tem como objetivo apresentar um pouco sobre mim, minhas habilidades e os projetos que já desenvolvi ao longo da minha jornada na programação.

Aqui você poderá conhecer melhor meu trabalho, as tecnologias com as quais tenho experiência e alguns dos projetos que já criei.

## 🎯 Objetivo

Criar um espaço para apresentar minha evolução como desenvolvedor, demonstrar meus conhecimentos e reunir meus principais projetos em um único lugar.

## 🚀 Sobre o projeto

O site foi desenvolvido utilizando tecnologias e ferramentas que fazem parte dos meus estudos e projetos, buscando aplicar na prática conceitos de desenvolvimento web, organização de código, responsividade e criação de interfaces.
